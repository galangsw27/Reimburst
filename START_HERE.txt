================================================================================
  🚀 AIRism - Quick Deployment Guide
================================================================================

LANGKAH CEPAT (5 MENIT):

1. Setup Environment
   $ cp .env.production .env
   $ openssl rand -base64 32
   $ nano .env  # Paste JWT_SECRET hasil generate di atas

2. Deploy
   $ ./deploy.sh

3. Akses
   Web:      http://localhost:3000
   Database: localhost:5432
   Health:   http://localhost:3000/api/health

================================================================================

COMMANDS:

  make install    - Install dependencies
  make deploy     - Deploy application
  make start      - Start services
  make stop       - Stop services
  make logs       - View logs
  make health     - Check health
  make monitor    - Monitor system
  make db-shell   - Database shell
  make db-backup  - Backup database
  make clean      - Clean everything

================================================================================

TESTING:

  ./scripts/test-deployment.sh  - Test deployment
  npm run test:run              - Run tests
  make health                   - Check health

================================================================================

  QUICKSTART.md              - 5-minute quick start

TROUBLESHOOTING:

  Port in use:      lsof -i :3000
  Database error:   docker-compose restart postgres
  Reset all:        make clean && ./deploy.sh
  View logs:        make logs

================================================================================

REQUIREMENTS:

  ✅ Docker 20.10+
  ✅ Docker Compose 2.0+
  ✅ 2GB RAM
  ✅ Port 3000 & 5432 available
